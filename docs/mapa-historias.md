HU-01 — Catálogo de espacios
Como visitante de Expocentro, quiero visualizar los espacios disponibles para identificar cuál puede adaptarse a mi evento.

La página:
/espacios

debería mostrar tarjetas como:
┌────────────────────────────┐
│       [Fotografía]         │
│                            │
│ Salón Los Zorzales         │
│                            │
│ Capacidad: xxx personas    │
│ Tipo: Salón                │
│                            │
│       Ver espacio →        │
└────────────────────────────┘

Criterios de aceptación
- Mostrar fotografía.
- Nombre del espacio.
- Descripción breve.
- Capacidad.
- Botón Ver detalles.
- Diseño responsive.
- Todos los espacios utilizan el mismo diseño.


HU-02 — Detalle de un espacio
Esta agrega bastante valor al sitio.

Como visitante, quiero consultar las características de un espacio para determinar si cumple las necesidades de mi evento.

URL futura:
/espacios/zorzales

o inicialmente:
/Espacios/Detalle/1

La página podría contener:
------------------------------------------------
              SALÓN LOS ZORZALES

         [ Fotografía principal ]
------------------------------------------------

Descripción

Capacidad
XXX personas

Tipos de montaje

✓ Auditorio
✓ Escuela
✓ Banquete

Características

✓ Aire acondicionado
✓ Área de montaje
✓ Acceso
✓ Servicios audiovisuales

[ Solicitar cotización ]
------------------------------------------------

Criterios de aceptación
Debe mostrar:
- Nombre.
- Galería o fotografía.
- Descripción.
- Capacidad.
- Características.
- Servicios disponibles.
- Botón Solicitar cotización.
Ese botón después debería mandar al usuario a:
/solicitar-cotizacion?espacio=1
