1. Redefinición del enfoque del proyecto

Se decidió cambiar el enfoque inicial orientado a usuarios externos y solicitudes comerciales de Expocentro hacia un sistema de uso interno para colaboradores de CCIC.

El nuevo objetivo del sistema consiste en permitir que los colaboradores registren solicitudes de eventos internos, indicando datos generales, salón, montaje, servicios, alimentación y otros requerimientos.

Se definieron inicialmente los siguientes roles:

Solicitante interno.

Coordinador de eventos.

Administrador.

También se estableció que, en una etapa posterior, los usuarios internos podrán autenticarse mediante Microsoft Entra ID utilizando sus cuentas institucionales.

2. Definición de las pantallas mínimas del MVP

Se definieron las principales pantallas necesarias para la primera versión funcional:

Inicio / Dashboard.

Nueva solicitud – Datos generales.

Nueva solicitud – Montaje.

Nueva solicitud – Servicios y alimentación.

Resumen y envío.

Mis solicitudes.

Detalle de solicitud.

Se estableció que el proceso de creación de una solicitud será desarrollado como un formulario por etapas, permitiendo mantener la solicitud en estado Borrador mientras el usuario completa la información.

El flujo definido fue:

Inicio
   ↓
Nueva solicitud
   ↓
Datos generales
   ↓
Montaje
   ↓
Servicios / Alimentación
   ↓
Resumen
   ↓
Enviar solicitud
   ↓
Mis solicitudes
   ↓
Detalle de solicitud
